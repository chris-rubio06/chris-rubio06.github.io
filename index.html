01PREDICTIVE ANALYTICS

Customer Churn Prediction

7,043customer records
80.55%test accuracy

I built a machine learning project to predict whether telecommunications customers would cancel their service. I cleaned and analyzed 7,043 customer records, explored customer behavior, and compared Logistic Regression with Random Forest.

Logistic Regression achieved 80.55% test accuracy. An interactive ipywidgets tool lets users adjust tenure, contract type, and monthly charges to estimate cancellation probability.
